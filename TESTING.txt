1. PREREQUISITES & SETUP
================================================================================

Before running any tests, ensure these are ready:

  [A] Kubernetes cluster running (Docker Desktop)
      kubectl get nodes
      Expected: desktop-control-plane   Ready

  [B] Operator deployed
      kubectl get pods -n aperture-system
      Expected: aperture-operator-xxx   1/1   Running

  [C] Inference pod running
      kubectl get pods -n default -l app=aperture-inference
      Expected: opt-125m-workload-inference-xxx   1/1   Running

  [D] Port-forwards active (run port-forward.ps1 or manually):
      kubectl port-forward svc/kube-prometheus-stack-grafana 3000:80 -n aperture-monitoring
      kubectl port-forward pod/<inference-pod> 8080:8080 -n default

  [E] Python 3.11 installed with httpx:
      python --version          # Python 3.11.x
      pip install httpx         # for benchmark

5. API ENDPOINT TESTS (Manual)
================================================================================

All commands below use PowerShell Invoke-RestMethod.
Ensure port-forward to 8080 is active first.

--- Test 5.1: Health Check ---
Invoke-RestMethod http://localhost:8080/health | ConvertTo-Json

EXPECTED:
{
  "status": "healthy (fallback)",
  "model": "facebook/opt-125m",
  "tokens_generated": 0,
  "token_quota": 50000,
  "uptime_seconds": 123.4
}

WHAT TO CHECK:
  - status = "healthy (fallback)" means CPU mode is active
  - status = "healthy" means GPU/vLLM is loaded
  - token_quota should be > 0
  - uptime_seconds should be increasing

--- Test 5.2: Generate Endpoint (Basic) ---
$body = '{"prompt":"What is Aperture AI?","max_tokens":30}'
Invoke-RestMethod http://localhost:8080/generate -Method POST `
  -ContentType "application/json" -Body $body | ConvertTo-Json

EXPECTED:
{
  "text": "[CPU Fallback] What is Aperture AI? → Aperture AI is a GPU-orchestrated...",
  "tokens_generated": 20
}

WHAT TO CHECK:
  - text field is non-empty
  - tokens_generated > 0
  - No error field in response

--- Test 5.3: Generate with max_tokens variation ---
# Short response
$body = '{"prompt":"Hello","max_tokens":5}'
Invoke-RestMethod http://localhost:8080/generate -Method POST `
  -ContentType "application/json" -Body $body

# Long response
$body = '{"prompt":"Explain transformers in detail","max_tokens":100}'
Invoke-RestMethod http://localhost:8080/generate -Method POST `
  -ContentType "application/json" -Body $body

WHAT TO CHECK:
  - Short: tokens_generated <= 5
  - Long: tokens_generated approaches 100

--- Test 5.4: Token Quota Enforcement ---
# First check remaining quota
Invoke-RestMethod http://localhost:8080/health | Select-Object -ExpandProperty token_quota

# Submit request larger than remaining quota
$body = '{"prompt":"test","max_tokens":999999}'
try {
  Invoke-RestMethod http://localhost:8080/generate -Method POST `
    -ContentType "application/json" -Body $body
} catch {
  Write-Host "Error: $($_.Exception.Response.StatusCode)"
}

EXPECTED: HTTP 429 Too Many Requests
Response body: {"error":"quota_exceeded", ...}

--- Test 5.5: Prometheus Metrics Endpoint ---
Invoke-RestMethod http://localhost:8080/metrics

EXPECTED output (Prometheus text format):
  # HELP aperture_requests_total Total number of HTTP requests handled.
  # TYPE aperture_requests_total counter
  aperture_requests_total 134

  # HELP aperture_tokens_generated_total Total tokens generated since startup.
  aperture_tokens_generated_total 0

  aperture_token_quota 50000
  aperture_token_quota_remaining 50000
  aperture_avg_request_latency_ms 0.336
  aperture_uptime_seconds 594.15
  aperture_engine_loaded 0

WHAT TO CHECK:
  - All 7 metrics present
  - aperture_engine_loaded = 0 (CPU mode) or 1 (GPU mode)
  - aperture_requests_total increments on each call

--- Test 5.6: Invalid Request Validation ---
# Missing prompt field
$body = '{"max_tokens":30}'
try {
  Invoke-RestMethod http://localhost:8080/generate -Method POST `
    -ContentType "application/json" -Body $body
} catch {
  Write-Host "HTTP $($_.Exception.Response.StatusCode)"
}
EXPECTED: HTTP 422 Unprocessable Entity

# Negative max_tokens
$body = '{"prompt":"test","max_tokens":-1}'
EXPECTED: HTTP 422 Unprocessable Entity

--- Test 5.7: API Docs Available ---
Start-Process "http://localhost:8080/docs"
EXPECTED: Swagger UI opens with /generate, /health, /metrics endpoints

--- Test 6.4: Verify metrics increment after API call ---
# Step 1: record current value
$before = (Invoke-RestMethod http://localhost:8080/metrics) -split "`n" | 
  Select-String "aperture_requests_total " | Select-Object -Last 1

# Step 2: make 10 requests
1..10 | ForEach-Object {
  Invoke-RestMethod http://localhost:8080/health | Out-Null
}

# Step 3: check new value
$after = (Invoke-RestMethod http://localhost:8080/metrics) -split "`n" | 
  Select-String "aperture_requests_total " | Select-Object -Last 1

Write-Host "Before: $before"
Write-Host "After:  $after"
# EXPECTED: after value is 10 higher than before

--- Test 7.3: Manual concurrency test ---
# Run 20 parallel requests using PowerShell jobs
$jobs = 1..20 | ForEach-Object {
  Start-Job -ScriptBlock {
    $body = '{"prompt":"What is machine learning?","max_tokens":20}'
    Invoke-RestMethod http://localhost:8080/generate -Method POST `
      -ContentType "application/json" -Body $body
  }
}
$results = $jobs | Wait-Job | Receive-Job
$results | ForEach-Object { Write-Host "Tokens: $($_.tokens_generated)" }

EXPECTED: All 20 jobs return tokens_generated > 0, no errors

--- Test 7.4: Check results CSV ---
Import-Csv "e:\aperture ai\inference\benchmarks\results\load_test_summary.csv" | Format-Table

EXPECTED columns:
  concurrency, total_requests, successful, failed,
  p50_ms, p95_ms, p99_ms, mean_ms, min_ms, max_ms, throughput_rps

12. DEBUGGING GUIDE
================================================================================

PROBLEM: Pod in CrashLoopBackOff
  kubectl logs <pod> -n default -c inference --previous
  kubectl describe pod <pod> -n default
  LOOK FOR: Permission denied, getpwuid error, CUDA errors

PROBLEM: Init:Error (preloader crashes)
  kubectl logs <pod> -n default -c model-preloader
  LOOK FOR: HuggingFace download errors, /tmp write permission
  FIX: kubectl describe pod — check Events section

PROBLEM: /generate returns 'NoneType not callable'
  The SamplingParams vLLM call is before the fallback check
  FIX: Ensure fallback check comes before SamplingParams() in server.py

PROBLEM: Prometheus shows target DOWN
  kubectl get podmonitor -n default
  kubectl describe podmonitor -n default
  CHECK: label selector matches pod labels

PROBLEM: Grafana shows "No data"
  1. Check datasource: Settings → Data Sources → Prometheus → Test
  2. Check UID: should be PBFA97CFB590B2093
  3. Query Prometheus directly: localhost:9090

PROBLEM: Port-forward keeps dying
  RUN: powershell -File "e:\aperture ai\port-forward.ps1"
  KEEP THAT WINDOW OPEN

PROBLEM: Helm lint fails
  helm lint helm/aperture-ai/ --debug   # shows exact template error
  helm template aperture-ai-test helm/aperture-ai/ 2>&1  # render all
